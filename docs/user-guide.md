# 用户指南

面向最终用户的日常操作（Web 与桌面完全一致，桌面复用同一前端）。

## 实时看板

- 状态徽：`实时已连接` / `连接 real-time-feed…` / `模拟行情`（feed 两次重试
  不可达自动降级，确定性序列，刷新可复现）。
- `sync seq` 显示同步序号；丢帧诊断见该数字跳变。
- 价格跳变闪烁：红涨绿跌（A 股口径），平盘（0）归红。
- `?feedWs=ws://host:port/ws` 可覆盖 feed 地址（默认同主机 8082）。
- SMA(5) 由滚动收盘窗口现场计算。

## 工作区（多标签页）

- 标签条切换 / 新建 / 重命名（Enter 确认、Escape 取消）/ 删除。
- 每个工作区存一套自选标的（6 位数字代码，上限 30）。
- 存于浏览器 `alpha.workspaces`，隐私模式写入失败不阻塞使用。
- 活动工作区的标的集驱动看板订阅。

## 导出 CSV

看板「导出 CSV」按钮下载当日快照
（`symbol,name,price,change_pct,volume,updated_at`）。
单标的历史序列导出走市场数据 API `/stocks/:symbol/history.csv`
（见 `docs/market-data-api.md`）。

## 隐私

右下角隐私面板：一键导出本地数据快照（`alpha.` 应用键全量 JSON），
一键清除（显式清单 + 前缀扫描，未来新增键自动纳入）。
服务端只存公开行情，不存个人数据（见 `docs/data-privacy.md`）。

## 主题

浅色 / 深色 / 跟随系统（默认跟随）。桌面窗口边框跟随 OS（Tauri v1 限制），
页面内三态照常生效。

## 移动端

- Android 小组件：桌面 glance，120 秒过期灰显，点击直达标的分析
 （见 `docs/android-widget.md`）。
- 长按图标快捷方式：直达贵州茅台 / 平安银行。
- 通知需显式开启（opt-in），见应用内隐私设置。

## 视频教程（边界登记）

视频录制与托管管线尚未立项——本指南即文字版教程唯一事实源；
录制管线（录屏 → 剪辑 → 托管 → 站内嵌入）登记为后续增量，不预写占位。
